# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview

This activity introduced me to the role of a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. It focused on getting familiar with a cloud-based Linux environment and basic cloud administration tasks.

## Objectives

* Access a cloud-based Linux environment using KillerCoda
* Learn basic Linux navigation and commands
* Check basic system information
* Organize files and folders
* Create a GitHub portfolio repository
* Document the activity using Markdown

## Activities Performed

1. Started an Ubuntu environment using KillerCoda
2. Created a new user with sudo access
3. Checked the system information, including the OS, kernel, CPU, memory, and storage
4. Created folders for Documents, Notes, Reports, and Screenshots
5. Created and edited Markdown documentation files
6. Created and prepared a GitHub portfolio repository

## Linux Commands Used

* `adduser`, `usermod`, `su`
* `whoami`, `pwd`, `hostname`
* `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
* `mkdir`, `ls`, `nano`, `touch`, `cat`

## Skills Learned

I learned the basics of using Linux, including navigating directories, managing users, and checking system information. I also learned how to organize files, create Markdown documents, and start using GitHub for my cloud computing portfolio.
