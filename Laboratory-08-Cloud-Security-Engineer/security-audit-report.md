# Security Audit Report

### The Principle of Least Privilege (PoLP)

The Principle of Least Privilege means providing users, programs, and processes only the permissions they need to perform their tasks. This is important for cloud accounts because if an account gets hacked, the attacker will have limited access to the system. Giving only the necessary permissions helps prevent unauthorized activities and reduces the risk of serious damage.

### Attack Surface

An attack surface refers to all the possible entry points that hackers could use to access a virtual machine or system. These include open ports, active services, installed applications, and user accounts. Reducing the attack surface makes a system more secure by removing unnecessary services and disabling features that are not needed.

### Default Deny Policy

A Default Deny Policy means blocking all incoming traffic unless a specific connection is allowed. This approach is safer because it prevents unknown or unauthorized connections from accessing the system. Instead of blocking threats one by one, it allows only trusted and necessary traffic, helping protect the server from potential attacks.
