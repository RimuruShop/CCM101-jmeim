# Laboratory Activity 5: Mission 5 – The Cloud Data Engineer

## Mission Overview

In this activity, I learned about the differences between Block, File, and Object Storage. I also deployed an S3-compatible object storage server using MinIO and Docker. I created a storage bucket and uploaded a file to verify that the deployment was working properly. This activity helped simulate a practical task that a cloud data engineer might perform.

## Objectives

- Understand the differences between Block, File, and Object Storage
- Set up an S3-compatible Object Storage server using MinIO and Docker
- Access a cloud service through a web interface using port forwarding
- Create a storage bucket and upload files to the cloud
- Record and explain cloud storage activities using Markdown
- Continue building a professional Cloud Computing Portfolio on GitHub

## Tools Used

- **KillerCoda Playground** – Ubuntu and Docker environment
- **Docker** – Used to run the MinIO container
- **MinIO** – S3-compatible object storage service
- **GitHub** – Used for the cloud computing portfolio

## Skills Learned

- Understanding different cloud storage types and their appropriate uses
- Deploying a service inside a Docker container using environment variables
- Accessing a cloud service through port forwarding
- Creating storage buckets and uploading files using a web console
- Properly documenting technical activities and deployments using Markdown
