# Cloud Provider Comparison

| Infrastructure Component             | AWS                         | Microsoft Azure               | Google Cloud Platform |
| ------------------------------------ | --------------------------- | ----------------------------- | --------------------- |
| Compute                              | EC2 (Elastic Compute Cloud) | Virtual Machines (Azure VMs)  | Compute Engine        |
| Storage                              | S3 (Simple Storage Service) | Blob Storage                  | Cloud Storage         |
| Networking                           | VPC (Virtual Private Cloud) | Virtual Network (VNet)        | VPC Network           |
| Identity and Access Management (IAM) | AWS IAM                     | Microsoft Entra ID (Azure AD) | Cloud IAM             |

## Guide Questions

1. **Which cloud provider offers the broadest range of services?**

AWS is commonly considered to have the widest selection of cloud services. As one of the earliest major public cloud platforms, it provides a large variety of tools covering areas such as computing, storage, artificial intelligence, IoT, databases, and data analytics.

2. **Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**

Microsoft Azure would be a suitable choice because it works closely with Microsoft products and services such as Microsoft 365, Active Directory, and Windows Server. This integration can make identity management and system administration easier for organizations already using the Microsoft ecosystem.

3. **Which platform is widely recognized for AI, ML, and Kubernetes services?**

Google Cloud Platform is widely recognized for its capabilities in artificial intelligence, machine learning, and Kubernetes. Google developed Kubernetes and provides AI and ML tools such as Vertex AI, making it a strong platform for organizations working with these technologies.

4. **What similarities did you observe among the three cloud providers?**

The three cloud providers offer many of the same fundamental cloud infrastructure services, including compute, storage, networking, and identity management. They also provide pay-as-you-go pricing models, container orchestration services, and data centers distributed across different regions to improve availability, redundancy, and performance.
